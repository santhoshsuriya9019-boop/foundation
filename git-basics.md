# Commit a local change to repository
- Open git bash
- cd  ~/OneDrive/Desktop/practice/foundation
- Command to know the local unstaged changes `git status`
- Command to stage a change `git add <file>`
- Command to commit a change(local) `git commit -m <message>`
- Command to view the commits `git log`
- Command to push the local commits to repository `git push origin main`
- Verify the changes in github portal
